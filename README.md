# Ib · 空缺

**在线试玩**：[https://ib-museum-demo.app.workbuddy.host](https://ib-museum-demo.app.workbuddy.host/?sharecode=5WGABVAYL7) （电脑浏览器，键盘 + 鼠标；首次进页面要下 56 MB，等十几秒）

一款 3D 第一人称恐怖游戏 Demo。闭馆前的最后一夜，你站在父亲的遗作回顾展里，发现馆里的人都没有脸。

## 关于这个项目

- 主角是七岁的 Ted。场馆按他的身高做（相机 1.15 m，成人视平线在屏幕上方），所以整个美术馆都显得过高、过大。
- 灵感只借形式，不借设定：**《恐怖美术馆 Ib》** 的"人山人海 → 空无一人"、**《Doctor Who》哭泣天使**的"被看着就不动"、**《层层恐惧》**的"视线离开就变样"。世界规则是本作自己的。
- 学习项目：为练 Blender 建模 + Unity 开发而做，非商业，素材只用于学习。目标长度约 30 分钟，一局到底。使用与转载的限制见文末[免责声明](#免责声明)。

## 玩法

- **逛**。画中馆人山人海，但所有观众都是固定站位、面朝作品、互不交谈。他们的脸不是马赛克，是没画完的笔触——五官位置对，边缘化开。这一段的任务只有一个字：逛。
- **出画**。上二楼与全家福互动，镜头锁在画上慢慢拉回，展厅从四周褪成黑色。你回到开场那间黑屋，转身，门的位置变成一个空画框。穿过去，落回真实馆——回头，《美术馆》已经挂在墙上，观众席少了一个小人。
- **布展**。走出全家福厅后人全没了，灯还亮着。馆藏在你看不见的时候重新布展：门变成墙、名画换成人、雕像转过身。原因不是闹鬼，是它们在归位。全片 7 处，只发生一次，不碰关键路线。
- **停电与手电**。走到楼梯中段全馆断电。摸到二楼厕所捡起手电，光扫过长廊的那一下，值班室的门正在慢慢滑开。拿起手电的瞬间，人偶与名画人物开始动。
- **三段任务**：值班室读交接本、看监控（天使出动）→ 穿过雕塑厅、**倒退着**进配电间取工作卡 → 前台抽屉取主门钥匙。三段跑完，你已经把这个馆走熟了。
- **盯着它们**。哭泣天使只在一楼，不被注视时移动，被盯满 3 秒转为追击，追起来永不放弃——所以过雕塑厅要倒着走。名画人物在二楼必追，值班室是唯一的安全区。
- **两个结局**。钥匙到手后，下楼把钥匙插进正门 = 坏结局；揣着钥匙不碰门、回二楼走进那片空白 = 真结局。没有确认窗口，不能反悔。
- **你打不过任何东西**。没有生命值、没有反击手段，被接触就是 Game Over。唯一的数值是奔跑体力，死了自动回到最近的检查点。

## 操作

| 按键 | 作用 |
|---|---|
| W A S D / 方向键 | 移动（走 3.2 m/s） |
| 鼠标 | 环顾（第一人称） |
| Shift | 奔跑（5.4 m/s，消耗体力，满体力约能连跑 3.75 s） |
| Ctrl | 蹲下（1.5 m/s，更矮、脚步更轻；蹲展柜后面**不是**掩体） |
| E | 交互（看展品、拾取、开门、推门） |
| F | 手电筒开关 |
| Esc | 暂停 / 设置（音量、鼠标灵敏度） |

## 技术

- **Unity 6（6000.5.5f1）+ URP + New Input System**。输入用代码构建 `InputAction`，不引用 `.inputactions` 资产，预制体拷到别的工程不会静默失效。
- **整个馆是程序化灰盒**：菜单 `Tools/Ib/生成灰盒关卡` 一键重建墙体、楼板、门洞、展台、人台、礼服、灯具、光影，尺寸全在文件顶部常量里。改关卡改常量，不手拖场景（重跑会覆盖手改内容）。
- **模型**：灰盒白模 → ProBuilder 细修 → 成品用 Blender 模块化套件；雕像与人偶由 Blender + Tripo + Hyper3D 出模，贴图（墙面、地板、石纹、画布、模糊脸）多为脚本程序生成。
- **"视线外才改变"**：`GeometryUtility.TestPlanesAABB` 判断包围盒进没进视锥，再对包围盒 27 个采样点打射线判遮挡（`Unseen.cs` / `ChangeWhenUnseen.cs`），不用 `Renderer.isVisible`——那会把阴影投射和 Scene 视图也算成"看见"。
- **天使 AI**：Still / Peek / Attack 三阶段 + NavMesh 巡逻与追击，注视时石像化、移开视线后位移（`WeepingAngel.cs`）。
- **90 多个 C# 脚本**，分 `Core / Player / Interaction / Environment / Threats / UI / Flow` 七层；相机单一写者（位置归 Controller、旋转归 Look），避免多脚本争同一属性。
- **WebGL**：Gzip 压缩 + 解压回退，不需要服务器配 Content-Encoding，丢到任意静态托管就能跑。

## 本地运行

用 Unity Hub 打开本工程（**Unity 6000.5.5f1**），打开场景 `Assets/Scenes/Graybox.unity`，按 Play。

关卡是生成出来的，不是手摆的。重新生成：

```
菜单 Tools/Ib/生成灰盒关卡
```

打 WebGL 包：`File > Build Settings` 切到 WebGL → Build；或命令行 `-buildTarget WebGL`。压缩格式用 Gzip 并勾选 Decompression Fallback（`Player Settings > Publishing Settings`），产物可以直接静态托管。
